Graduate Profile (PEI)

Upon graduating from Technical-Professional Secondary Education, students will have developed the ability to:

  • Develop low- and medium-complexity programs and routines involving data structures and databases according to the company's requirements.
  • Install manufactured information systems to obtain the necessary information according to the company's requirements.
  • Develop applications and routines for the maintenance and updating of databases according to the company's requirements.
  • Build computer applications based on object-oriented programming, in order to meet technical and user requirements.
  • Develop web applications according to requirements and using the programming languages available on the market, enabling the management and publication of information on the internet.
  • Implement preventive and corrective software maintenance plans in order to promote its productivity.
  • Provide technical support to users of a computer system, locally or remotely, meeting technical and user requirements.
  • Install and update hardware and software components in an organization, in order to boost performance and/or fix common errors.
  • Install and configure operating systems on personal computers in order to connect them to a LAN, meeting the established quality and security standards.
  • Install productivity software and utility programs on a personal computer, according to user requirements.
